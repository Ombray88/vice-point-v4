Vice Point 3D — a 3D open-world crime game in WebGL2: drive a neon-dusk coastal city, steal cars, outrun the police and a helicopter, run seven story jobs for the fixer Mara Voss, tune cars at the garage, repaint at the spray shop, hide at the safehouse. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC. Key systems include a 3D chase camera, dynamic traffic and pedestrians, a wanted star system with police pursuit and helicopter units, 7 chained story missions, procedural WebAudio with 3 radio stations, and a game save/load system.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
